Third Quill Support

Third Quill for macOS

Found a bug, or have a question or a suggestion? Open a request and it will be answered there.

Contact support

Requests are handled through GitHub Issues. A free GitHub account is needed to post one. Please don't attach PDFs that contain personal or confidential information: issues are public.

Getting started

Open a PDF with ⌘O, or drop it on the window. Nothing you do changes the original file. When you are done, choose File > Save As… (⌘S) and the result is written to a new file.

  • Pages — select thumbnails, then rotate, delete, reorder, insert or split from the toolbar or the Pages menu.
  • Forms — Form > Fill Form… (⇧⌘F). Click a field on the page and type, then click Apply.
  • Marks — Marks > Add Marks… (⇧⌘S). Pick seal, text, highlighter or image from the toolbar, click or drag on the page, then click Place.

Common questions

Fill Form is grayed out.
The PDF has no fillable form fields. Many forms are only printed boxes and lines, with no fields behind them. You can still write on those with a text mark (Marks > Add Marks…).

Some fields are gray and can't be filled.
Signature fields, read-only fields and push buttons are shown but can't be filled. On some versions of macOS, groups of radio buttons can't be filled either, because the choice would not survive saving. Rest the pointer on a gray field to see the reason.

Can I sign with a digital certificate?
No. A seal or an image of your signature can be placed on the page, but certificate-based digital signatures need a dedicated signing tool.

Can I black out (redact) text?
No. A black box drawn over text leaves the text underneath readable, so Third Quill doesn't offer it.

A PDF won't open.
PDFs that need a password to open aren't supported. PDFs that only restrict printing or copying open normally. A damaged or incomplete file is refused with a message saying so.

Using it with an AI assistant

Third Quill includes an MCP server, so an AI assistant on the same Mac can work on PDFs too.

  • Open Settings (⌘,) and choose Add Folder… for each folder the assistant may use. It can't open files anywhere else.
  • Click Copy Configuration and paste it into your MCP-compatible client's settings.
  • The server runs only while Third Quill is open. It listens on 127.0.0.1 (this Mac only), port 8765 by default.

The assistant doesn't see a tool, or describes it wrongly.
Most clients read the list of tools once, when they connect. After updating Third Quill, restart the client or reconnect it.
